# Conveyor Belt and Bottle Handling System

## Overview

This project is a PLC-based conveyor belt and bottle handling system developed using **CODESYS**.

The system focuses on controlling a conveyor belt and managing bottle positions through PLC programming. It combines different programming languages and control elements to represent an industrial automation process.

**Project Status:** 🚧 In Progress 🚧

## System Features

- Conveyor belt Start/Stop control.
- Bottle position management.
- Photocell sensor input.
- Bottle data management using arrays and structures.
- Visualization of the conveyor belt, bottles, sensor, and control buttons.

## Programming Implementation

The project uses different PLC programming languages:

### Ladder Diagram (LD)
Used to implement the basic control logic, including Start/Stop commands and conveyor motor control.

### Structured Text (ST)
Used to implement the bottle management logic, including:
- Conditional statements (`IF`).
- Iterative operations (`FOR` loops).
- Array manipulation.
- Bottle position and movement calculations.
- Structured data management using custom data types.

## Technologies and Tools

- CODESYS
- Ladder Diagram (LD)
- Structured Text (ST)
- PLC Programming
- CODESYS Visualization

## Project Objectives

The main objective is to develop practical skills in PLC programming and understand how different programming languages can be combined to control and manage an industrial conveyor system.
